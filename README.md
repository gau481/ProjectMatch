Project Match

A web app prototype that helps university students find project teams that need their skills.

Live prototype: https://gau481.github.io/ProjectMatch/

The problem

In our survey (n = 58 students, 12 Sep 2026), 36 respondents named at least one difficulty finding teammates. The most common were: most students were already in groups (16), they did not know who else was looking for a group (14), and they knew few other students (13).

What the prototype does
A student creates a profile with university, skills and interests.
The app ranks open projects by how well they match the student's skills (match percentage).
The student reads project details and sends a join request.
The leader's contact is shown only after the request is approved.

Security

User text is displayed as plain text, so code typed into a field (for example an HTML tag) is shown as text and never runs.
